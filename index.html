    PPN 11% dan PPH 2,5% terisi otomatis dari Total Nilai Barang × NDPBM. Bea Masuk manual — tarifnya berbeda per HS Code. Mengetik sendiri menghentikan pengisian otomatis; kosongkan untuk mengaktifkannya lagi. PDRI = Bea Masuk + PPN + PPH, dihitung seketika.

    EXIM·DDI

    Sistem pelacakan jadwal import & export internal — ETD, ETA, dokumen kepabeanan, dan daftar barang dalam satu papan.

    Catatan data

    Data tersimpan permanen di database online (Supabase). Bulk Export mengunduh seluruh jadwal pada buku yang aktif sebagai file Excel, dan Bulk Import memuatnya kembali dengan format yang sama.

    Ctrl K cari cepat · / fokus pencarian · N jadwal baru ·
